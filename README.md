# Карантин покупок

Telegram-бот для паузы между импульсом купить вещь и осознанным выбором товара.

## Возможности MVP

- приватный доступ по `ALLOWED_USER_IDS`;
- добавление желания через пошаговый диалог без запроса ссылки;
- расчёт карантина по цене и хранение в SQLite;
- первая проверка через 24 часа, одно повторное напоминание и завершение карантина;
- продление ожидания, отказ, этап выбора, до трёх вариантов, финальная пауза 24 часа;
- фиксация покупки и вопрос о пользе через 7 дней;
- статистика отдельно для каждого пользователя;
- защита уведомлений от дублей через таблицу `notifications`;
- SQLite WAL и long polling.

## Простые решения и ограничения

- Изменение часового пояса и удаление истории технически подготовлены в настройках, но в MVP не выполняют полную бизнес-операцию.
- Ссылки на товары сохраняются как текст и не открываются ботом.
- Если уведомление попадает в тихие часы 22:00-09:00, оно переносится на конец тихих часов.
- FSM-диалоги после перезапуска могут сброситься, но сохранённые желания остаются в базе.

## Запуск без Docker

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

Заполните `.env`:

```env
BOT_TOKEN=telegram-token
ALLOWED_USER_IDS=111111111,222222222
TIMEZONE=Europe/Moscow
DATABASE_PATH=data/bot.db
```

## Docker

```bash
docker build -t purchase-quarantine-bot .
docker run -d --restart unless-stopped --env-file .env -v "$(pwd)/data:/app/data" purchase-quarantine-bot
```
